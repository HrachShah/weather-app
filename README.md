# Weather App

A visually rich weather application featuring real-time weather data, interactive 3D globe visualization, and dynamic map integration.

## Features

- **Real-time Weather Data**: Fetches current weather from OpenWeatherMap API
- **3D Globe Visualization**: Interactive Three.js rendered sphere that responds to temperature
- **Interactive Map**: Leaflet-based map showing location coordinates
- **Dynamic Styling**: Temperature-responsive visual effects

## Tech Stack

- HTML5 / CSS3 / JavaScript
- Three.js (3D rendering)
- Leaflet (maps)
- OpenWeatherMap API

## Setup

1. Get an API key from [OpenWeatherMap](https://openweathermap.org/api)
2. Replace `API_KEY` in `Untitled-3.js` with your key
3. Open `Untitled-1.html` in a browser
